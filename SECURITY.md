# Security

ATAR's reference demo is offline and does not request brokerage credentials. Do not add API keys, account information, private keys or operational configuration to issues, examples or source files.

Do not run untrusted strategy or configuration code in an environment containing trading credentials. Review third-party adapters before using them. Public research examples should use synthetic or properly redistributable data.

For a suspected vulnerability, use GitHub's private vulnerability reporting when enabled. Otherwise contact the maintainer through the contact methods on their GitHub profile. Do not publish exploitable details or secrets in a public issue. No unmonitored security email address is asserted here.

The release checklist and scans are defense-in-depth, not a security certification. A maintainer should review the complete candidate release and its history before changing repository visibility.
