# Third-party dependencies

ATAR's author-owned released code is under Apache-2.0. Dependencies keep their own licenses and are installed separately. The core uses NumPy, pandas and json5. The development test suite uses pytest.

VBT Pro is an optional commercial dependency. ATAR calls its public Python API in a small adapter and a PinBar signal integration. No VBT Pro source code, installation package, private documentation, license key or vendor assets are bundled. The reference quickstart does not import or require VBT Pro.

Names such as VBT Pro, Bill Williams and R3 identify dependencies or research strategy families. They do not imply endorsement, affiliation or exact correspondence to another author's complete strategy specification.
